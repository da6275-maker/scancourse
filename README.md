# 스캔코스

종이에 적힌 주소를 폰 카메라로 찍으면 글자를 읽어서 지도에 번호를 찍고, 가까운 순서로 코스를 만들고, 각 지점에서 카카오내비·카카오맵·티맵·네이버지도로 바로 넘겨주는 현장용 웹앱입니다. 설치 없이 브라우저로 쓰고, 홈 화면에 추가하면 앱처럼 열립니다.

## 쓰는 순서

1. **스캔** — 사진 찍기(또는 앨범에서 여러 장 선택). 10~30초 뒤 주소 목록이 나옵니다.
2. **목록** — 줄마다 원본 조각이 같이 보이니 틀린 글자만 고치고, 출발지를 고른 뒤 **지도에 올리고 순서 만들기**.
3. **코스** — 지도와 번호 목록. **내비 시작**(다음 지점) 또는 줄의 **내비 ▸**를 누르면 앱이 열립니다. 다녀온 곳은 **완료**.
4. **코스 링크 복사**로 동료에게 같은 코스를 보낼 수 있습니다.

## 처음 한 번 설정 (관리자)

1. `config.js`의 `KAKAO_JS_KEY`에 카카오 개발자 사이트(developers.kakao.com)에서 받은 **JavaScript 키**를 넣습니다.
2. 카카오 개발자 사이트 > 내 애플리케이션 > 앱 설정 > 플랫폼 > **Web** 에 이 사이트 주소(예: `https://아이디.github.io`)를 등록합니다. (앱 설정에 "카카오맵" 사용 설정이 있으면 켭니다.)
3. `config.js`의 `DEFAULT_REGION`(기본 지역), `DEFAULT_HOME`(회사 주소)도 맞게 고칩니다.

## 직원 폰에 설치하기

주소: https://da6275-maker.github.io/scancourse/

- 갤럭시: 크롬으로 열면 첫 화면에 **📲 홈 화면에 설치** 버튼이 뜹니다. 안 뜨면 크롬 메뉴(⋮) → **홈 화면에 추가**
- 아이폰: 사파리로 열고 공유 버튼 → **홈 화면에 추가**
- 설치하면 홈 화면 아이콘으로 열리고 주소창 없이 앱처럼 동작합니다. 업데이트는 자동(다음에 열 때 반영).

## 파일 구성

- `index.html` 화면, `app.js` 동작, `core.js` 주소 정리·순서 계산, `config.js` 공통 설정
- `tess/` 글자 인식 엔진(tesseract.js 5, Apache-2.0)과 한국어 모델. 폰 안에서만 돌아가고 사진은 어디로도 보내지 않습니다.
- 주소 → 좌표: 카카오맵 API. 순서: 공개 경로 서버(OSRM, 도로 기준) → 실패하면 직선거리.
- 목록과 코스는 각자 폰(브라우저 저장소)에만 남습니다.
